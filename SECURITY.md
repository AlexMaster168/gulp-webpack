# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.x     | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly:

1. **Do NOT** open a public GitHub issue.
2. Email the maintainer or use [GitHub's private vulnerability reporting](https://github.com/AlexMaster168/gulp/security/advisories/new).
3. Include steps to reproduce the issue.
4. You can expect an initial response within **48 hours**.
5. Accepted vulnerabilities will be patched as soon as possible.

## Security Measures

- All dependencies are automatically monitored via [Dependabot](https://github.com/dependabot).
- CI/CD pipelines run security audits on every pull request.
- Only maintained, up-to-date packages are used.
